Octop 桌面客户端（免安装压缩包 · 本地版 slim）
============================================

这是免安装版本：解压即用，不需要运行任何安装程序，也不会往系统里写注册表。

使用步骤
--------
1. 把本压缩包解压到任意目录。
   建议放在用户目录下（例如 D:\Apps\Octop），不要放在 Program Files 里
   —— 那里需要管理员权限，普通用户写不进去。

2. 双击 Octop.exe 启动。

3. 首次启动会联网下载完整运行环境（约 290 MB），状态栏会显示下载进度。
   下载完成后解压到本地，之后可以离线使用。

如果双击没反应 / 被 Windows 拦下
---------------------------------
从网上下载的压缩包，解压出来的文件可能仍带"来自互联网"标记（Mark of the Web），
Windows 会因此弹出"Windows 已保护你的电脑"并拒绝运行。

按顺序试这三种办法（任选其一，成功后就不必再试下一个）：

  1) 先运行本目录下的 Unblock.bat（双击即可），然后再双击 Octop.exe
  2) 右键 Octop.exe -> 属性 -> 底部勾选"解除锁定" -> 确定 -> 再双击
  3) 右键本 zip 文件 -> 属性 -> 勾选"解除锁定" -> 确定 -> 删掉已解压的目录，重新解压

提示"缺少 WebView2 运行时"
--------------------------
Windows 10 / 11 一般自带 WebView2 运行时，通常无需处理。
若确实缺失，可到微软官网下载 "Microsoft Edge WebView2 Runtime" 的
Evergreen Standalone Installer 安装。

数据放在哪里
------------
客户端的配置与运行时文件放在：

  %USERPROFILE%\.octop\

可用环境变量 OCTOP_HOME 改到别处。

卸载
----
不需要卸载程序：
  1) 删除解压出来的文件夹
  2) 删除 %USERPROFILE%\.octop 目录（会一并删掉本地数据与运行时）

版本
----
版本号见 Release 说明，或在客户端"关于"页面查看。
